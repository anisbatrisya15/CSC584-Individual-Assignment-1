# CSC584-Individual-Assignment-1
Project Description: A Java web application built with Servlets and JSPs (in MVC pattern) captures user profile data via an interactive form, processes it via HTTP POST and dynamically displays the results.

Technologies Used:-
- Backend: Java Web (Java Servlets, JSP)
- Frontend: HTML5, CSS
- Architecture: Model View Controller (MVC)
- Development Environment: NetBeans IDE
- Web Server:  GlassFish Server (4.1.1)
- Build/JDK Tooling: JDK 1.8.0_202

Prerequisites:-
- Before running the application, ensure you have the following installed:
1. Java Development Kit (JDK 8+)
2. NetBeans IDE (with Java EE support enabled)
3. GlassFish Application Server (configured inside NetBeans)

How to Run the Application:-
1. Clone or Extract Project:
- Download or extract the project directory to your local machine.
   
2. Open in NetBeans:
- Launch NetBeans IDE.
- Go to File > Open Project and select the project folder (Personal Profile).

3. Build and Run:
- Right-click the project name in NetBeans and click Clean and Build.
- Right-click the project and select Run.
- NetBeans will deploy the application to your local server and automatically open index.html in your default browser.
